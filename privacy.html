Privacy Policy

นโยบายความเป็นส่วนตัวสำหรับบอท "ฝากบอก"

มีผลตั้งแต่วันที่ 20 สิงหาคม 2026

1. บทนำ

นโยบายความเป็นส่วนตัวฉบับนี้อธิบายว่า บอท Discord "ฝากบอก" มีการเก็บ ใช้ และจัดการข้อมูลที่เกี่ยวข้องกับการใช้งานบริการอย่างไร

เราให้ความสำคัญกับความเป็นส่วนตัวของผู้ใช้ และจะใช้ข้อมูลเท่าที่จำเป็นต่อการทำงานของระบบ

2. ข้อมูลที่อาจถูกจัดเก็บ

เมื่อคุณใช้งานระบบฝากบอก ข้อมูลต่อไปนี้อาจถูกจัดเก็บ:

  • Discord User ID ของผู้ส่ง
  • Discord User ID ของผู้รับ
  • Discord Guild/Server ID
  • Discord Channel ID ที่เกี่ยวข้อง
  • Discord Message ID ที่เกี่ยวข้อง
  • ข้อความที่ผู้ใช้ส่งผ่านระบบฝากบอก
  • คำใบ้ที่ผู้ใช้ระบุ
  • ข้อความตอบกลับ
  • วันที่และเวลาที่เกี่ยวข้องกับข้อความ
  • สถานะว่าข้อความได้รับการตอบกลับแล้วหรือไม่

3. วัตถุประสงค์ในการใช้ข้อมูล

ข้อมูลที่จัดเก็บจะถูกใช้เพื่อวัตถุประสงค์ในการให้บริการ และการทำงานของบอท เช่น:

  • ส่งข้อความฝากบอกไปยังผู้รับที่เลือก
  • แสดงข้อความในช่อง Discord ที่ผู้ดูแลกำหนด
  • ตรวจสอบว่าผู้ใช้เป็นผู้รับข้อความหรือไม่
  • อนุญาตให้ผู้รับตอบกลับข้อความ
  • แจ้งเตือนผู้ส่งเมื่อมีการตอบกลับ
  • ป้องกันการตอบกลับข้อความเดียวกันหลายครั้ง
  • จัดการการตั้งค่าของบอทในแต่ละ Server
  • แก้ไขปัญหาและดูแลความเสถียรของระบบ

4. การจัดเก็บข้อมูล

ข้อมูลของระบบถูกจัดเก็บในฐานข้อมูล MongoDB ซึ่งใช้สำหรับการทำงานของระบบฝากบอก

ข้อมูลจะถูกเก็บไว้ตราบเท่าที่มีความจำเป็นต่อการให้บริการ หรือจนกว่าจะมีการลบตามกระบวนการที่เหมาะสม

5. การเปิดเผยข้อมูล

เราจะไม่ขายข้อมูลส่วนบุคคลของผู้ใช้ ให้กับบุคคลอื่นเพื่อวัตถุประสงค์ทางการตลาด

อย่างไรก็ตาม ข้อมูลอาจถูกเปิดเผยเมื่อจำเป็นต่อ:

  • การให้บริการของระบบ
  • การปฏิบัติตามกฎหมายหรือคำสั่งที่มีผลตามกฎหมาย
  • การป้องกันการใช้งานที่ผิดกฎหมายหรือการโจมตีระบบ
  • การแก้ไขปัญหาทางเทคนิคและการรักษาความปลอดภัย

6. ข้อความฝากบอกและความเป็นส่วนตัว

ระบบฝากบอกมีวัตถุประสงค์เพื่อส่งข้อความไปยังผู้รับ แต่ผู้ใช้งานควรหลีกเลี่ยงการส่งข้อมูลที่มีความอ่อนไหว หรือข้อมูลส่วนตัวที่ไม่จำเป็นผ่านระบบ

ผู้ใช้ควรรับผิดชอบต่อข้อมูลที่ตนเลือกส่งผ่านบอท

7. ความปลอดภัยของข้อมูล

เราพยายามใช้มาตรการที่เหมาะสมเพื่อป้องกันข้อมูล จากการเข้าถึง การแก้ไข หรือการเปิดเผยโดยไม่ได้รับอนุญาต

อย่างไรก็ตาม ไม่มีระบบออนไลน์ใดที่สามารถรับประกันความปลอดภัย ได้อย่างสมบูรณ์แบบ

8. ข้อมูลจาก Discord

บอททำงานผ่านแพลตฟอร์ม Discord และการใช้งาน Discord อยู่ภายใต้ข้อกำหนดและนโยบาย ความเป็นส่วนตัวของ Discord ด้วย

ข้อมูลที่ Discord ให้แก่บอทจะถูกนำมาใช้เท่าที่จำเป็น สำหรับการทำงานของฟังก์ชันที่ผู้ใช้เรียกใช้งาน

10. การเปลี่ยนแปลงนโยบาย

เราอาจปรับปรุงนโยบายความเป็นส่วนตัวนี้เป็นครั้งคราว เพื่อให้สอดคล้องกับการเปลี่ยนแปลงของบริการ หรือข้อกำหนดที่เกี่ยวข้อง

วันที่มีผลของนโยบายฉบับปัจจุบันจะแสดงอยู่ด้านบนของหน้านี้
